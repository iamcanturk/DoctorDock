Amaç: birkaç GitHub yıldızı + birkaç X takipçisi.

Küçük bir proje. Buna göre az efor. Tek oturuşta yapılıp bitirilecek 3 hamle, gerisi yok.

Gerçekçi ol: Yıldız çoğunlukla tek bir iyi paylaşımdan gelir (Show HN ya da Reddit tutarsa). Takipçi yavaş büyür. Kasmaya çalışma; bir kez düzgün göster, sonra bırak. Tutarsa güzel, tutmazsa proje portföyünde iyi bir iş olarak kalır.

30–60 dakikada 3 hamle

  1. Isınma ~5 dk

    3–5 arkadaşına/çevrene "çıktı, bir yıldız atar mısın" de. İlk 10–15 yıldız repo'nun boş görünmesini engeller; yeni gelen daha rahat yıldızlar.

  2. X'e tek bir tweet + sabitle ~10 dk

    Aşağıdaki tweet'i at, sağlık kartı görselini ekle, sonra tweet'i profilinde sabitle. Takipçi bu sabitlenmiş tweet'ten damlar.

  3. Tek bir toplulukta paylaş ~20 dk

    İkisinden birini seç (ikisini birden yapma, enerji ister): teknik kitle istiyorsan Show HN, Docker kullanıcıları istiyorsan r/docker. Paylaş, sonra 1–2 saat ara ara gelen yorumlara cevap ver.

Bu kadar. Zamanlama takıntısı yok; en iyisi Salı–Perşembe TR saatiyle ~16:00 (ABD sabahı) ama ne zaman enerjin varsa at. Tuttuysa yorumlara cevap ver, tutmadıysa dert etme.

Yıldızı kolaylaştıran, zaten hazır olan şeyler

  • README (mascot, sağlık kartı, demo GIF, net kurulum) ✓
  • GitHub topics + sosyal önizleme görseli ✓
  • Landing sayfası (doctordock.iamcanturk.dev) ✓
  • Tek eklenecek: launch tweet'ini sabitle · GitHub profil bio'na repo linkini koy.
Yıldız isterken: "Beğendiysen bir yıldız çok iyi olur" demek normaldir. Ama Show HN / Reddit'te asla "upvote verin" deme (yasak, gönderini gömer). Sadece işe yaradıysa, doğal biçimde yıldız iste.
